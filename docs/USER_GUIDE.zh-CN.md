# RecordAssistant 用户使用手册

## 开始使用

安装并启动后，RecordAssistant 会载入一组可删除的演示数据。所有修改都会即时保存在本机。建议先在“设置与备份”中导出一次 JSON，熟悉备份流程后再录入正式内容。

## 今日总览

首页只显示当前有内容的今日任务、项目进度、近期节点和重要事件。勾选任务即可更新完成状态。

## 项目进程

点击“项目”建立项目，再展开项目添加里程碑和任务。项目及里程碑进度按任务权重自动计算。

## 关系图谱

先添加人物，再通过以下任一方式建立关系：

1. 点击“关系”，在表单中选择两位人物；
2. 按住一个人物的头像，将连线拖到另一人物头像上。

拖动人物姓名可调整节点位置，布局会自动保留。点击“自动排版”可重新整理节点。指向人物时会突出其直接关系；点击节点编辑人物，点击关系线编辑评分与关系事件。

## 事件时间线

事件可以归入工作、组织、会议、行政、人际或其他类别，并关联多个项目、人物和关系。关系表单中的“同时记录一次关系事件”会把该记录同步到时间线。

删除任务或普通事件后，可在 6 秒内点击“撤销”。

## 备份与恢复

点击“导出”生成完整 JSON 备份。恢复时选择“导入”，确认前会自动下载当前数据备份。

## 数据说明

数据保存在应用所使用的本机 WebView2 存储中。卸载、清理应用数据或更换设备前，请先导出 JSON 备份。桌面端和浏览器端各自使用独立的本地存储空间，可通过导入导出转移数据。
